# NOL 티켓 · 기아 홈 가을야구 예매 도우미

예매처는 **NOL(야놀자) 티켓**입니다.  
[포스트시즌 페이지](https://nol.yanolja.com/ticket/genre/sports/postseason)에서  
**기아 홈(광주 챔피언스필드)** 상품이 뜨면 **좋은 자리 2연석**을 고르고 **결제 직전**까지 갑니다.

- 로그인 / 본인인증 / **결제**: 직접 (NOL 계정)
- 자동: NOL 상품 감시 → `예매하기` → 대기열 → **`확인하고 예매하기`** → **3연석**(테이블석 우선) → 결제 화면에서 정지

## 지금 상황 (참고)

| 단계 | 장소 | NOL 예매 |
| --- | --- | --- |
| 와일드카드 | 잠실 (LG vs 두산) | 이미 오픈된 상품 있음 |
| **준PO 1·2·5차전** | **광주 (기아 홈)** | 공지되면 이 도구로 노림 |
| 준PO 3·4차전 | 잠실 | 홈 아님 (기본 제외) |

기아 홈 상품이 아직 없으면 `npm run dry-run` 결과에 광주/기아가 안 뜹니다.  
준PO 예매 공지 후 `npm start` 하면 됩니다.

## 준비

```bash
npm install
npx playwright install chromium
```

`config.json`에서 선호 좌석·키워드를 바꿀 수 있습니다.  
기본은 **3연석**, **중앙테이블·테이블석(3인) 우선**, 그다음 미니/내야/3루입니다.  
결제 직전에서 멈추고, 카드/간편결제는 직접 합니다.

### 경기일 (준PO 1차전 예: 14:00 오픈)

```bash
# 13:40 KST부터 준비 → 오픈 시 3연석 → 결제 직전
npm run game-day

# 시각 변경 예
PREP_AT=13:40 SEAT_COUNT=3 npm run game-day
```

## 실행

```bash
# 상품만 확인
npm run dry-run

# 기아 홈이 뜰 때까지 감시
npm run watch

# 로그인 → 오픈 대기 → 2연석 → 결제 직전
npm start
```

브라우저가 열리면:

1. **NOL 로그인** (직접)
2. 필요 시 **본인인증** (직접)
3. 스크립트가 좌석 잡고 결제 화면까지 진행
4. **결제는 직접** 완료

로그인 세션은 `.browser-profile/` 에 저장됩니다.

## 좌석 기준 (야구 몰라도 되게)

우선순위 대략:

1. 중앙 / 테이블 / 내야  
2. 기아 응원 쪽 **3루**  
3. 외야·스카이박스·시야방해는 피함  

`config.json` 의 `preferredGrades` / `avoidGrades` 로 조정하세요.

## 보안문자 (OCR 최대 2회)

좌석/예매 중 보안문자가 뜨면:

1. 이미지 캡처 → `tesseract.js` OCR (전처리: 그레이스케일·이진화)
2. 입력·제출, 실패 시 새로고침 후 **최대 2회**
3. 그래도 실패하면 Take Control 수동 입력 대기(기본 90초)

인식률은 왜곡 문자에 따라 들쭉날쭉합니다.

## 주의

- NOL 이용약관상 매크로·비정상 예매는 취소될 수 있습니다. **본인 직관용 1회** 전제입니다.
- 좌석 UI가 바뀌면 자동 선택이 실패할 수 있습니다. 그 경우 브라우저에서 좌석만 고르고 결제하면 됩니다.
- 이 도구는 카드 정보를 입력하지 않습니다.
